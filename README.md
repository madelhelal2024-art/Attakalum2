# التكلّم — السلسلة الصوتية للأطفال

صفحة هبوط عربية RTL للسلسلة الصوتية، مبنية بـ **HTML + CSS + JavaScript** بدون أي إطار عمل أو خطوة بناء. جميع العناوين والبطاقات والأزرار والنصوص عناصر HTML حقيقية قابلة للتعديل.

## التشغيل

- افتح `index.html` محليًا، أو شغّل خادمًا محليًا من مجلد المشروع: `python -m http.server 8080`.
- للاستخدام عبر GitHub Pages: ارفع **كامل المجلد بما فيه `assets/`** إلى جذر فرع `main`، ثم فعّل **Settings → Pages → Deploy from a branch → main → /(root)**.
- يمكن رفع الملفات ذاتها إلى أي استضافة صفحات ثابتة أو تضمينها في منشئ مواقع مع مراعاة مسارات الصور.

## هوية التصميم

- لون أساسي: `#0B6B64`، لون ثانوي: `#0F8A7F`، أصفر ذهبي: `#FFC107`، برتقالي: `#FF7A00`.
- الخط: **Cairo** (يحمّل من Google Fonts مع خط احتياطي).
- صور الهيرو وعوالم المستويات الأربعة مقدّمة من صاحب المشروع، ومحسّنة بصيغة WebP. النصوص فوق الصور ليست جزءًا ثابتًا من الصور.

## ملاحظات مهمة قبل الإطلاق

- روابط النماذج الصوتية والمرئية والكتب **غير مقدمة**؛ لذلك أزرارها معطلة عمدًا، ويجب تفعيلها فقط عند إرفاق ملفات أو روابط معتمدة.
- الشعارات وأغلفة الكتب الرسمية لم تُقدَّم كملفات مستقلة؛ لذلك لا تُعرض أغلفة مفبركة على أنها رسمية. الشعار النصي في الترويسة مؤقت ويُستبدل لاحقًا بالشعار الأصلي.
- أزرار التواصل تحيل إلى واتساب `+20 102 320 1001`، مع رسائل مختلفة للأهالي والمعلمين والمؤسسات. لا تُجمع بيانات على الخادم.
- جميع الأقسام الأربعة عشر والـ FAQ موجودة. التعليمات العربية متطابقة مع المسودة المعتمدة المرفقة قدر الإمكان.
